## Titanic Survival Prediction using Machine Learning Pipeline

This project is part of my Data Science with Python Internship – Task 5. It uses a complete Scikit-learn pipeline to preprocess the Titanic dataset, train a Logistic Regression model, evaluate performance using Classification Report, Confusion Matrix, ROC-AUC, and 5-Fold Cross-Validation, and save the trained model with Joblib for future predictions.

## Technologies Used
- Python
- Pandas
- NumPy
- Matplotlib
- Scikit-learn
- Joblib

## Model Used
- Logistic Regression (`max_iter=1000`)

## Evaluation Metrics
- Accuracy
- Precision
- Recall
- F1-Score
- ROC-AUC
- Cross-Validation

## Output
- `Task5_Titanic_Machine_Learning.ipynb`
- `model.joblib`

## Key Insight
The project demonstrates a complete and reproducible machine learning workflow for binary classification using the Titanic dataset.
